WooCommerce Order Importer

Importa pedidos desde WooCommerce a Odoo de forma automática y sencilla

Este módulo proporciona una integración completa entre WooCommerce y Odoo, permitiendo importar pedidos de manera manual o automática según el intervalo configurado. Sincroniza clientes, productos y pedidos manteniendo toda la información relevante.

Características principales

Importación automática

Configura la frecuencia de importación que mejor se adapte a tu negocio: cada 15 minutos, 30 minutos, cada hora o diariamente.

Mapeo de estados personalizable

Define cómo se traducen los estados de pedidos de WooCommerce a los estados equivalentes en Odoo.

Historial detallado

Mantén un registro completo de todas las importaciones realizadas, incluyendo errores y estadísticas.

Creación automática de entidades

El sistema puede crear automáticamente clientes y productos si no existen en Odoo.

Soporte completo para pedidos

Importa correctamente productos, impuestos, gastos de envío y notas del cliente.

Configuración sencilla

Sólo necesitas configurar la URL de tu tienda WooCommerce y tus credenciales API para comenzar a importar pedidos.

Gestión de importaciones

Revisa el historial de importaciones y estadísticas desde un solo lugar.

Requisitos
  • Python 3.6 o superior
  • Odoo 14.0 o superior
  • Biblioteca Python WooCommerce (pip install woocommerce)
  • Acceso a la API REST de WooCommerce (v3) en tu tienda
